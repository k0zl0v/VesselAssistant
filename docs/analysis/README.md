## TL;DR

**Что это.** Offline-десктоп (Tauri + React + SQLite), заменяющий ручной Excel-файл учёта перевалки зерна на судне-накопителе: партии по трюмам, автоматическое LIFO-списание для таможни, крановые поправки, журнал событий SOF, экспорт подписываемых документов в XLSX. Работает без интернета — как и требует жизнь на рейде.

**Удовлетворяет ли запрос.** Ядро — да: расчёты сверены с реальным Excel в пределах 0.001, LIFO и связь журналов автоматизированы, 113 тестов зелёные. Но «MVP закрыт по 22 FR» — с оговорками: 5 FR частичны (нет PDF, автобэкапов, защиты закрытого рейса, полного импорта Excel, «кто изменил» в аудите пуст).

**Главные риски.** (1) Нет автобэкапов на судовом ПК с нестабильным питанием; (2) нет файлового лога/ErrorBoundary — полевые баги невоспроизводимы; (3) закрытый рейс редактируется; (4) UX не прощает человеческих ошибок — нет undo/edit, необратимые действия в один клик, ошибки по-английски с UUID.

**Что делать дальше.** P0: автобэкап, guard закрытого рейса, файловый лог, фикстура импорт-тестов. P1: PDF-экспорт, оператор в аудите, защита audit_log, копирование рейса. Полный список — в [05](./05-gap-analysis.md), UX-улучшения — в [04](./04-ux-review.md).
